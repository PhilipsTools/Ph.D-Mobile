Upload everything in this folder to a host that serves it over https.

  GitHub Pages     new repo - Add file - upload these - Settings -
                   Pages - Deploy from branch - main - / (root)
  Cloudflare Pages Create a project - Direct Upload - drag this folder in

Then on the phone open the https address in Safari and
Share > Add to Home Screen. No certificate, no profile.

The hospital list here is empty on purpose - real customer names
stay on the PC. Add sites on the phone with '+ Add hospital'.

Re-run 'dev\make_web_copy.py' and re-upload whenever questions change.
